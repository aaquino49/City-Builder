# Tiny Swords art

Sprites in this folder (except `custom/`) are from **Tiny Swords** by **Pixel Frog**
(https://pixelfrog-assets.itch.io/tiny-swords) — the legacy "Update 010" release, licensed
**CC0 1.0** (public domain). Files were renamed/reorganized; pixels are unmodified.

`custom/` contains sprites generated for this project in the Tiny Swords style (walls, gates and
buildings the legacy pack doesn't include). The `custom/` sprites were generated with OpenAI's
image model (ChatGPT) for this project in the Tiny Swords style, then cleaned up to a true pixel grid.
